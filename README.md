# Generador de árbol de Navidad con nombres

Escribe los nombres y genera un árbol con las letras soldadas en una sola pieza.
Exporta **SVG** (rojo = corte, azul = marcado, verde = base) para xTool/láser y **3MF** (base + letras) para Bambu Lab.

Todo funciona en el navegador, sin servidor: abre `index.html`.

La carpeta `build/` contiene las fuentes y librerías y `build.ps1` para regenerar `index.html` a partir de `template.html`.

Fuentes incluidas (SIL OFL): Titan One, Lilita One, Chango, Bowlby One.
